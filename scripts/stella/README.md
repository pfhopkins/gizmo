# Stella production configurations

`Config_stella_{default,cloud,tallbox}.sh`, `stella_{cloud,tallbox}.params`: the stella_dev production set in this tree's flag and parameter names.
`STELLA_DEFAULTS` is the plan's default set; the configs add the opt-ins that reproduce stella_dev production:
`GALSF_FB_PHOTOIONIZATION_PER_DIRECTION`, `GALSF_FB_RADPRESSURE_COUNT_6_8EV_TWICE`. Set the table paths and the IC in the params.
