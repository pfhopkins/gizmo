# sgchem_rt_cr

The moment solver and the cosmic-ray fluid together with SGChem, a few steps from a fresh start in a uniform box. Electrons at the network's value within a factor 2, no gas speed above 1 km/s, gas + cosmic-ray + bin energy within 10 %. Needs the cr series. Without the start electrons of `sgchem_rt_start` this setup has Ne = 1e-56 at the first force pass.
