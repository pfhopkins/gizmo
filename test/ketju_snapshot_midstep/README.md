# ketju_snapshot_midstep

Snapshots of KETJU region members part-way through their step: an isolated binary (P ~ 250 yr) in a region whose steps
span ~40 orbits, written at times inside those steps. Each snapshot's separation is compared with the exact two-body
orbit. Members mid-step used to be written on the velocity-trick drift chord (errors of order the orbit); their state is
now integrated to the output time by a copy of the region's MSTAR system.
