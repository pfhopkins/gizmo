# single_stars_no_gas_kernel_growth (narrow)

A single-star event whose kernel reaches no gas widens the kernel x1.4 and tries again in the same step, at most 3 times
(bubble retry). Setup of `test/single_stars_forced_events`, the first star in an empty sphere of 3.5 pc with its
feedback kernel set to 3 pc before the loop (`TEST_SINGLE_STARS_FEEDBACK_KERNEL_AT_MOST`). Bar: both forced supernovae couple in their own step, mass conserved.
