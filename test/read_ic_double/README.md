# read_ic_double

HDF5 ICs keep their stored precision: Coordinates, Velocities and Masses of a double IC read back
exactly, and a float IC reads exactly its float values (bit-identical to the old float path).

64 PartType4 stars, no forces (SELFGRAVITY_OFF), 2 MPI ranks; the t=0 snapshot
(OUTPUT_IN_DOUBLEPRECISION) is compared with the IC for a float64 and a float32 IC.
The IC is generated by `make_read_ic_double_ics.py`; nothing is downloaded.
