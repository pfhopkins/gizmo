# crfluid_streaming_cap

`CRFLUID_STREAMING_LOSS_CAPPED_AT_CR_SPEED`: the Alfven speed in the CR streaming loss is at most the CR speed. A periodic box with an
Alfven speed of 3000 km/s, a CR speed of 300 km/s and a CR gradient along the field. Bars: CR energy lost with the cap at most half of
the loss without; within 5 % of stella_dev on the same ICs.
