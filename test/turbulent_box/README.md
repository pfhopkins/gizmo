# turbulent_box

Driven isothermal turbulence in a periodic box, held at a target Mach number by the
`TURB_DRIVING_TARGET_SIGMA` control loop.

| | |
|-|-|
| units | pc - km/s - Msun |
| box | 10 pc, periodic, 32^3 cells on a lattice, initially at rest |
| EOS | `EOS_GAMMA=1.001`, `EOS_ENFORCE_ADIABAT=0.04`: isothermal, c_s = 0.2 km/s |
| driving | solenoidal, parabolic spectrum on 1 <= kL/2pi <= 3 peaked at k = 2, coherence time L/(2 v_rms) |
| target | Mach 10, i.e. 3D mass-weighted v_rms = 2 km/s |
| mass | 3875 Msun: alpha_vir = 5 sigma_3D^2 L / (6 G M) = 2 at Mach 10 |
| gravity | off (`SELFGRAVITY_OFF`) |
| variants | hydro / MHD (`MAGNETIC`, `MHD_CONSTRAINED_GRADIENT=1` as in STARFORGE runs, uniform B_z = 1.6 uG, plasma beta 1), each with the driving force recomputed every step (`full`) or only on driving updates every 0.5 = t_cross/10 (`lazy`, `TURB_DRIVING_UPDATE_FORCE_ON_TURBUPDATE`) |

The ICs are generated by `make_turbulent_box_ics.py`; builds without `MAGNETIC` ignore their field.
The analysis and checks live in `turb_driving_common.py`, shared with `test/turbsphere`.

**Gravity.** This is the stirring phase. The mass is already set for alpha_vir = 2, so removing
`SELFGRAVITY_OFF` turns on a self-gravitating box, but with no sinks nothing stops isothermal
collapse once it starts.

**What is checked.** The Mach number is measured from the snapshots, independently of the loop's
own measurement: mass-weighted rms velocity about the mean over the isothermal sound speed. After
2 t_eddy (t_eddy = `TurbDrive_MaxWavelength / TurbDrive_ApproxRMSVturb` = 5) the mean must be within
3% of the target and every snapshot within 10%, and the peak over the whole run, spin-up included,
must stay under 1.1x the target.
`mach_vs_time<variant>.png` shows the snapshot Mach number, the loop's measurement, the driving gain,
and for MHD the plasma beta.
