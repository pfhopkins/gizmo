# turbsphere

The STARFORGE stirring setup, held at a target Mach number by the `TURB_DRIVING_TARGET_SIGMA` control
loop in its aperture mode: the loop measures only the gas within R of the box centre.

| | |
|-|-|
| units | pc - km/s - Msun |
| geometry | uniform sphere, R = 5 pc, in a periodic box of 10 R = 50 pc; ambient gas at 1e-3 of the cloud density (MakeCloud defaults) |
| resolution | 32752 cloud + 7944 ambient cells of equal mass, on lattices, initially at rest |
| confinement | `STARFORGE_GMC_TURBINIT=2` analytic potential (uniform sphere plus r^-3 halo, scaled by alpha_vir), self-gravity off |
| EOS | `EOS_GAMMA=1.001`, `EOS_ENFORCE_ADIABAT=0.04`: isothermal, c_s = 0.2 km/s |
| driving | solenoidal, parabolic spectrum on wavelengths 2R/3 - 2R peaked at R, coherence time R/v_rms; lazy force (`TURB_DRIVING_UPDATE_FORCE_ON_TURBUPDATE`) updated every 0.5 = t_cross/10, as turbsphere stirring runs are always made |
| target | Mach 10 inside R, i.e. 3D mass-weighted v_rms = 2 km/s |
| mass | 3875 Msun in the cloud: alpha_vir = 5 sigma_3D^2 R / (3 G M) = 2 at Mach 10. This is the sphere inscribed in `test/turbulent_box` |
| variants | hydro / MHD (`MAGNETIC`, uniform B_z = 2.2 uG everywhere: beta 1 in the cloud, 1e-3 in the ambient, as MakeCloud's field is uniform) |

The ICs are generated by `make_turbsphere_ics.py`. `GravAccel_GMCTurbInit` hard-codes R = BoxSize/10
and a cloud mass fraction of 0.808; the ICs give 0.805.

**What is checked.** As `test/turbulent_box` (see `turb_driving_common.py`), with the Mach number
measured over the loop's aperture. The printout also reports the median radius of all gas, as a check
that the cloud is held, but it is not asserted on.
